Mijn Werkplanner 3.0

Bestanden uploaden naar de hoofdmap van je GitHub Pages repository.
De app bevat aanpasbare categorieën, kleuren, registraties wijzigen/verwijderen en lichte/donkere/automatische weergave.

Weergave instellen: Instellingen > Weergave.
Gegevens worden lokaal in de browser bewaard. Exporteer regelmatig een back-up.
Google Agenda-synchronisatie is nog niet actief.
